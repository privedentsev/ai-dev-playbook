### Критерии приёмки

- [ ] AC-01: Независимая матрица спецификации AC-01–11 воспроизведена с реальными CLI/subprocess counters, включая no-Git, ручные правки, unknown fallback, exclusions и release/stale/force; не только unit/структурная проверка.

- [ ] AC-03: Legacy/opt-in/update/recovery и cross-task reuse сохранены; отсутствуют открытые блокирующие находки. Измерения PB-064 воспроизводимы, обещания экономии соответствуют данным.

### План

1. Проверить зависимости, прочитать card show --handoff и связанные записи; выполнить audit-ready по действующему контракту.

Независимая сессия либо инженер, Python, временные проекты, доступный изолированный стенд для проверки прав. Если стенд отсутствует, явно зафиксировать непроверенную границу; не принимать защищённую эксплуатацию по mock-тесту.
