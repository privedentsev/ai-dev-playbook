## Передача

Реализовано 2026-09-29, ветка `dev`, изменения не закоммичены.

- `tests/test_cli.py`: 19 сценарных тестов через `playbook.main` в изолированных временных проектах.
  - `init`: предпросмотр без записи; установка комплекта; конфликт файлов отменяет запись целиком (существующий файл не повреждён); повторная установка отклоняется; отказ установки поверх исходного комплекта.
  - `check`: чистая установка проходит `check`; `--ready` отклоняет `needs_review` и проходит после настройки; битая ссылка, устаревший индекс и отсутствие комплекта дают ошибку.
  - `verify`: `--dry-run` печатает план без записи; отсутствие блока `verification`, неизвестная задача и `draft` отклоняются; успешный прогон пишет `report.json` и логи; падающая проверка помечает остальные `skipped`; изменение входов даёт статус `stale`; превышение `timeout_seconds` — `timeout`.
- `.github/workflows/checks.yml`: `unittest` и `check --ready` запускаются в GitHub Actions на push и pull request — автоматический контур перед принятием изменений. Локальных git-хуков не добавлено: они не устанавливаются автоматически; защита ветки настраивается на GitHub отдельно.
- Обновлены `docs/code-map.md`, `docs/architecture.md`, `CHANGELOG.md`.
