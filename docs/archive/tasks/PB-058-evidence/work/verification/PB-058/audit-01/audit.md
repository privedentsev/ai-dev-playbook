## A-01 — P1 — Явный вход сужается фильтром модуля

Критерии: AC-01, AC-03.
Источник: `checks_inventory.py:293–294`, `_group_inputs`.

При module.paths=`src/payments/*.py` и check.inputs=`["src/payments"]` resolved_inputs добавляет фильтрованный directory-вход того же пути. `_group_inputs` сохраняет patterns и игнорирует широкий строковый path-вход. `notes.md` получает только `{type: file}`, без SHA-256. После замены `old` на `new` diff сообщает `complete=true, fresh=true, changed=[]`.

Влияние: изменение байтов явно объявленного входа незаметно; потребитель может ошибочно переиспользовать результат. R-05/06 нарушены.
Исправление: объединять области без сужения явного входа; добавить регрессию для строкового path вместе с модульным фильтром. Изменение любого файла явного каталога должно менять снимок.

## A-02 — P2 — Отсутствующий вход не перепроверяется

Критерии: AC-03.
Источник: `checks_inventory.py:392–393,412–413`, финальная сверка watch_files/watch_dirs.

Снять два file-входа: `a-missing` и `src/payments/pay.py`. В hash_fn второго создать `a-missing`. Функция возвращает нормальный снимок с `path:a-missing={type: absent}`, хотя файл уже существует. В контрольные списки отсутствующие пути не добавляются.

Влияние: снимок может не соответствовать текущему кандидату без предупреждения о гонке; нарушены заявленная гарантия AC-03 и design §4.
Исправление: контролировать отсутствие при финальной сверке (включая отсутствующий каталог/предка); появление входа должно отклонять снимок либо приводить к его повторному согласованному построению.

## A-03 — P2 — Литеральный путь модуля превращается в каталог

Критерии: AC-01.
Источник: `checks_inventory.py:227–231`, `resolved_inputs`.

Допустимый module.paths=`["src/payments/pay.py"]` разрешается как `{type: directory, path: "src/payments/pay.py", patterns: [...]}`. Для существующего обычного файла snapshot падает: «вход 'src/payments/pay.py' не является каталогом».

Влияние: корректная политика с модулем из конкретного файла не работает.
Исправление: корректно различать литеральный file/path и область glob; добавить сквозную проверку resolved_inputs → snapshot для литерального файла.

## A-04 — P2 — Допустимое селективное исключение блокирует снимок

Критерии: AC-02.
Источник: `checks_inventory.py:355–358`, `descend_input`.

Module.paths=`src/payments/*.py`, явных check.inputs нет; одобренное excludes=`src/**/fixtures.bin`. Политика валидна, build_inventory исключает существующий `src/payments/fixtures.bin` с причиной. Snapshot через resolved_inputs падает с конфликтом, хотя fixtures.bin не совпадает с glob входа. Исключение проверяется до фильтра patterns.

Влияние: допустимая политика PB-057 работает в inventory и отказывает в snapshot; нарушен заявленный контракт селективных glob.
Исправление: отличать исключение вне выбранного набора от реальной коллизии. Добавить совместную регрессию validate_policy → inventory → resolved_inputs → snapshot; реальные конфликты с явными входами должны по-прежнему отклоняться.
