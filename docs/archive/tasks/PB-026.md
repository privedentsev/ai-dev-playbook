Legacy-карточка (без метаданных) закрывается по прежней политике — evidence-деревья переносятся целиком.
- `close` при настроенном `documents` работает через engine: план сохраняется в `work/lifecycle/plans/`, `--dry-run` показывает предпросмотр без записи; без раздела — прежний пошаговый путь.
- `promote_change` принимает `implemented`-изменение: тело заменяется payload'ом, прежняя редакция — снимок `revision-N.md` в `<stem>-evidence/`, `current_revision` увеличивается, изменение получает `accepted`.
