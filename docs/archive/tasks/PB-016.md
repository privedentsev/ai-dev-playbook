## Приёмка

- [x] План содержит исходную/целевую версии и идентификаторы, добавления, замены, удаления управляемых файлов, миграции и конфликты.
- [x] Сравниваются эталон установленной версии, текущее содержимое и новый релиз; локально изменённые управляемые файлы блокируют применение до явного разрешения.
- [x] Неизвестные файлы не удаляются; настройки и документы не подменяются шаблонами; одинаковое целевое состояние даёт пустой план.
- [x] План связан с отпечатками файлов и артефакта; изменение входов делает его устаревшим и требует нового предпросмотра.
- [x] Пути вне корня, символические ссылки в управляемых путях, недостоверный состав релиза, неподдерживаемый переход и незавершённая транзакция обрабатываются явно.
- [x] Сценарные тесты подтверждают отсутствие записи при предпросмотре и корректность конфликтов, добавлений и удалений.

## Выполнение и проверки

Планирование: карточка создана, реализация и поведенческие проверки не начаты.

Реализация 2026-09-29 (Devin / SWE-2 High, общий changeset блока PB-014–PB-018):

- `update plan <артефакт>` — предпросмотр без записи: версии и release_id обеих сторон, добавления/замены/удаления, kept и выводимые из управления, конфликты (`modified`/`missing`/`modified-remove`/`collision`), миграции с diff настроек, ручные шаги, drift (локальные правки, которые обновление не трогает), неизвестные файлы.
- `--resolve <путь>=release|keep` фиксирует решения; `--save` пишет `work/update/plan.json` со схемой, отпечатком артефакта и `before_fingerprint` состояния проекта (управляемые файлы, manifest, настройки, AGENTS.md, `docs/**/*.md`) — изменение входов делает план устаревшим.
- Неоднозначный релиз (тот же номер, иное содержимое), downgrade, необъявленный `updates_from` переход, повреждённый `release.json`, симлинки и пути вне корня — явные ошибки; незавершённая операция блокирует plan/apply.
- Разрешения по неконфликтным путям отклоняются; одинаковое целевое состояние — пустой план.

Проверки: `UpdatePlanTest` — пустой план, секции плана и отсутствие записи/каталога work при предпросмотре, `--save` и устаревание, блокировка apply при неразрешённом конфликте, неподдерживаемый переход, downgrade, неоднозначный релиз, испорченный release.json. `python3 -m unittest discover -s tests` — 98 тестов OK; `check --ready` — OK.
