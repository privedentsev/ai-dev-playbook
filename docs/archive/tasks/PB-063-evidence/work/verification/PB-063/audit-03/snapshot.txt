#### A-01 — Замечание
Серьёзность: P2
Критерии: AC-01
Проблема: статический preview молча теряет унаследованные unittest-тесты и не отмечает неопределённость.
Воспроизведение: tests/test_a.py содержит Base(unittest.TestCase) с test_ok и Child(Base) без новых методов; сравнить survey.catalog_entries с unittest.TestLoader.discover.
Факт: preview содержит только test_a.Base.test_ok, discover также содержит test_a.Child.test_ok; все unknowns пусты. Причина — _is_testcase/_catalog_entries рассматривают только прямые базы TestCase и собственные методы.
Влияние: пользователь получает неполный каталог без предупреждения; после одобрения первая проверка отклоняет фактически обнаруженный тест. Указание ограничения в HANDOFF не заменяет unknowns в пользовательском preview.
Критерий исправления: учитывать разрешимое наследование либо явно перечислять неподдержанные классы/файлы в unknowns и выводе preview; постоянный тест сравнивает фактические IDs с предсказанием или проверяет явное предупреждение.
