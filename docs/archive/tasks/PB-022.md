### PB-022-A1 — High: кодирование пути меняет адресата, включая посторонние ссылки при close

Источник: `document_links.py:190–212`, `playbook.py:334–351`, `documents.py:935–938`. После `unquote` сборщик не защищает литеральные `%`, `#`, `?` и двоеточие в первом сегменте. Даже пустая карта и неизменный источник превращают `a%23b.md` в `a#b.md`, `a%3Fb.md` в `a?b.md`, `a%2520b.md` в `a%20b.md`, `./a%3Ab.md` в `a:b.md`; меняются файл или схема URI. Генератор индекса также выдаёт неправильный адрес для файла `a#b.md`.

Воспроизведение: тесты `test_A1_*` в [audit-probes.py](PB-022-evidence/audit-probes.py). В subprocess-сценарии `init → index → check → close DEV-1 → check` исходная проверка проходит, `close` возвращает 0, но меняет не связанную с задачей ссылку в README и следующая проверка возвращает 1. Файл-адресат остаётся на месте. Влияние: существующая команда закрытия может повредить навигацию по проекту при успешном завершении.

Критерий исправления: кодировать именно компонент пути с сохранением адресата после URL-разбора; отдельно сохранять query/fragment и стиль ссылки; не изменять незатронутые адресаты. Покрыть bare/angle-ссылки, генерацию индексов и реальный `close`; после него проверка проекта и разрешение всех исходных адресатов должны проходить.

### PB-022-A2 — Medium: кодовые примеры переписываются

Источник: `document_links.py:70–85`. Маскирование inline code выполняется отдельно для каждой строки, поэтому многострочный code span не распознаётся. Блок с отступом в четыре пробела также разбирается как ссылка. Тест `test_A2_code_examples_preserved` переносит `docs/a.md → docs/archive/a.md`: внутри обоих примеров `b.md` меняется на `../b.md`.

Влияние: нарушается обещание побайтно сохранять кодовые примеры; check может требовать существования адресов из примера. Критерий исправления: общий scan для check/rewrite должен исключать многострочные code spans и indented code, сохраняя реальные ссылки рядом; подтвердить неизменность текста примеров и отсутствие ложных ошибок check.

### PB-022-A3 — Medium: затронутая неподдерживаемая ссылка не создаёт конфликт

Источник: `document_links.py:54–55,315–333`. Проверяется перемещение адресата, но не изменение базы при перемещении источника. Если `docs/a.md` содержит HTML-ссылку на соседний `b.md` и переносится в `docs/archive/a.md`, а `b.md` остаётся, `plan_rewrites` возвращает пустые updates/conflicts. Аналогичный результат для wikilink с явным относительным именем. HTML с некавыченным атрибутом вообще не обнаруживается: при переносе `b.md` конструкция `<a href=b.md>x</a>` также не даёт конфликта.

Воспроизведение: два теста `test_A3_*`. Влияние: план признаёт перенос бесконфликтным, хотя относительный адрес перестаёт указывать на исходный файл. Критерий исправления: проверять необходимость изменения ссылки по обоим расположениям источника и полной карте адресатов, распознавать затронутые HTML-атрибуты с кавычками и без них; возвращать адресный конфликт до записи.

### PB-022-A4 — Medium: валидная inline-ссылка со скобками в подписи молча пропускается

Источник: `document_links.py:48–50,158–171`. Для `[a [b] c](b.md)` scan не возвращает ссылку. Rewrite при переносе источника оставляет прежний адрес; check для такой же конструкции с `missing.md` возвращает пустой список ошибок. Воспроизведение: два теста `test_A4_*`.

Влияние: общий парсер пропускает обычный вариант заявленных inline-ссылок; битые адресаты не обнаруживаются, конфликт также не возникает. Критерий исправления: поддержать сбалансированные скобки в подписи либо явно обнаруживать неподдерживаемую затронутую конструкцию с конфликтом; для поддерживаемого варианта check и rewrite обязаны работать с одним адресатом. Добавить проверки вложенных/экранированных подписей и изображения внутри ссылки.
