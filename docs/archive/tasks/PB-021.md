### PB-021-A1 — High: найденный документ читается через symlink за корнем

Источник: `documents.py`, `load_catalog`, обход `base.rglob("*.md")` (также обход остальных Markdown в `load_catalog`). `safe_path` проверяет корни коллекций, но не найденные файлы до `resolve/read_text`.

Воспроизведение: `document-symlink-outside-root` создаёт `docs/specs/outside.md` как symlink на временный файл вне проекта с ID `spec:outside`; `document list` возвращает 0 и регистрирует этот внешний документ. Дополнительный сценарий `symlink-inside-material-directory` показывает, что каталог материала с вложенным symlink тоже принимается; это наблюдение не означает, что ссылка внутри материала уже разыменована.

Влияние: нарушена граница чтения каталога и явный запрет symlink; внешний файл может стать источником управляемых метаданных. **Исправление:** валидировать каждый обнаруженный путь до чтения/разыменования, определить и проверить обход содержимого каталогов материалов; внешние/внутренние/битые symlink должны давать ошибку с путём, без чтения цели. Повторить CLI и сравнение дерева.

### PB-021-A2 — Medium: материал может включать код, постоянные тесты и миграции

Источник: `documents.py`, `_cross_check` и сбор `component_roots` в `load_catalog`. Проверяется только нахождение материала внутри компонента; обратное включение не проверяется, `components[].migrations` не учитывается.

Воспроизведение: `material-contains-component-roots` задаёт `code=app/src`, `tests=[app/tests]`, материал `source=app`; `migration-is-material` регистрирует каталог `db`, указанный в `migrations`. Оба `document list` возвращают 0.

Влияние: каталог считает продуктовые файлы переносимыми evidence; следующий этап получает недопустимый состав. Перенос и потеря данных этим аудитом не заявляются. **Исправление:** исключить пересечения в обе стороны со всеми настроенными границами кода/тестов/миграций; обе фикстуры отклоняются, обычный evidence принимается.

### PB-021-A3 — Medium: у внешнего материала допускаются два владельца

Источник: `documents.py`, `_cross_check`: external пропускается до проверки уникального владельца.

Воспроизведение: `two-external-owners` регистрирует один точный URI `https://example.invalid/proof` у `spec:alpha` и `spec:beta`; код возврата 0. URI фикстурный, сетевой запрос не выполнялся.

### PB-021-A6 — Medium: некорректный тип поля теряет адресную диагностику
