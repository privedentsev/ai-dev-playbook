# PB-053: сохранение повторного аудита PB-052

Семь файлов из `work/audits/PB-052-reaudit-02` скопированы побайтно в `PB-052-reaudit-02/`. Оригиналы сохранены. В архивной PB-052 изменён только адрес ссылки в контексте; журнал, Status/Closed и sidecar не изменены. Материалы принадлежат PB-053: регистрация материалов закрытой PB-052 запрещена CLI. После будущего штатного закрытия PB-053 lifecycle должен перенести их и переписать входящую ссылку.

`preservation.json` содержит исходные SHA-256 семи файлов, исходный текст PB-052 и хеш её sidecar. Проверка: `python3 docs/tasks/PB-053-evidence/preservation_probe.py`. Она сравнивает исходники, сохранённые копии, архивную карточку и вызывает реальную `_prepare_staged` с проверкой доступности и SHA-256 в staged.

Исторические команды и пути внутри копии протокола/кода оставлены побайтно. `probes.py` является историческим доказательством с вычислением корня по исходному размещению; команда из протокола относится к оригиналу в `work/audits`. Для воспроизведения исправления PB-053 используется отдельная `preservation_probe.py`.
