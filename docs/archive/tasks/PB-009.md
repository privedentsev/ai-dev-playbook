## Цель и границы

У задач хранится время постановки (`Created`) и закрытия (`Closed`): обязательные поля шапки карточки, валидация в CLI, колонки в индексе, сортировка архива по `Closed`. Метки — локальное время автора с явным смещением. Закрытие автоматизировано командой `playbook.py close <ID>`: статус, метка, перенос в архив и индекс одной операцией. Карточки, заведённые до введения полей, заполняются `unknown`.

## Приёмка

- [x] `check` требует `Created`/`Closed` в каждой карточке, валидирует ISO 8601 с часовым поясом, `Closed ≥ Created` и `Closed` только у done/cancelled; `unknown` допустим для ретро-заполнения.
- [x] Индекс показывает «Создана»/«Закрыта» (дата и время) в обеих таблицах; архив сортируется по `Closed`, `unknown` — в конце по ID.
- [x] `playbook.py close <ID> [--status done|cancelled]` проставляет статус и `Closed` локальным временем со смещением, переносит карточку в архив и обновляет индекс; `done` допускается только из `in_review`.
- [x] Правила и шаблон описывают поля и источник времени; существующие карточки заполнены `unknown`.

Индекс: колонки «Создана»/«Закрыта» в формате `YYYY-MM-DD HH:MM`, архив сортируется по `Closed` по убыванию, `unknown` — в конце по ID.
