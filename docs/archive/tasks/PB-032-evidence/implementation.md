# PB-032: результат реализации

Исполнитель: Codex; модель: GPT-6. Дата: 2026-10-29. Ветка: dev.

- Новый `verification_policy.py` не запускает команды и не изменяет CLI.
- `applicability` вычисляет always/when_paths/checkpoint по scope и полным baseline/current картам. Неизвестная база требует проверку. `*` ограничен сегментом, `**` допускает ноль сегментов.
- `required_checks` объединяет обязательность реестра и плана; отсутствие обязательного registry ID и неподтверждённое исключение проваленной проверки блокируют готовность.
- `task_projection` сохраняет содержательный Markdown и metadata, исключая известные служебные квитанции. `policy_projection` допускает явно доказанный набор зависимых registry ID.
- `snapshot` фиксирует содержимое, absent, состав каталогов, проекции и названные environment facts; отклоняет symlink, work, специальные файлы и неканонические пути.
- `compare_snapshots`, `definition`, `reusable` проверяют отдельные связи без подмены снимка файловой операции.
- `coverage` требует результат каждого применимого ID. Runner обязан предварительно проверить provenance/свежесть и выбрать последний совместимый результат; формат immutable отчётов PB-031 не изменён. Policy hash owning-report передаётся в evaluation view, не записывается новым полем результата.
