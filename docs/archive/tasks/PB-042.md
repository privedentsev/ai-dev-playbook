## Задача

### Цель и границы

Исправить повторную генерацию индекса при возврате карточки к ранее индексированному состоянию. Реализация отдельно от PB-041, зависимости между ними нет. Запуск выполнения разрешён инженером 2026-10-25; требования и план приняты этим запросом.

### Контекст

Обнаружено при повторной проверке PB-041. [Проба](../../tasks/PB-041-evidence/fix-01/index-replay-probe.py), [результат](../../tasks/PB-041-evidence/fix-01/index-replay.log). index_command вычисляет plan_id из желаемого содержимого; engine находит старую завершённую операцию и не восстанавливает изменившийся индекс. Команда сообщает об актуальности ошибочно.

### Критерии приёмки

- [x] AC-01: цикл in_review → index → in_progress → index → in_review → index каждый раз даёт индекс, равный render_index; повтор без изменений не пишет файлы.
- [x] AC-02: повтор уже завершённого плана сохраняет корректную идемпотентность; прерывания и общая блокировка поддерживаются.
- [x] AC-03: постоянная регрессия воспроизводит ошибку до исправления и проходит после него.

### План

1. Уточнить границу между новым запросом генерации и повтором сохранённой операции.
2. Реализовать исправление, проверить цикл возвратов, no-op и восстановление.
3. Выполнить verify и handoff на независимый аудит.

### Ресурсы

Python 3.10+, стандартная библиотека. Исполнитель: Codex / GPT-6.1 Sol (название подтверждено инженером). Бюджет не задан. Учёт времени и чтения — в материалах задачи; точный расход токенов средой не предоставлен.
