# Продукт

## Согласовано

`ai-dev-playbook` — переносимый комплект правил, шаблонов и локальных CLI для организации работы AI-агентов над программными проектами. Этот репозиторий используется для развития самого комплекта.

## Границы

CLI устанавливает шаблоны, проверяет структуру и ссылки, ведёт индекс задач и запускает настроенные локальные проверки. Он не заменяет проверку поведения продукта или независимый аудит.

## Неизвестно

Целевая аудитория за пределами владельца, требования к распространению и политика бюджетов пока не зафиксированы.
