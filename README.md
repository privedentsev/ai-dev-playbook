# ai-dev-playbook

Переносимый комплект правил, шаблонов и CLI для работы AI-агентов над проектом. Исходный комплект находится в [`ai-dev-playbook/`](ai-dev-playbook/README.md).

Этот репозиторий использует собственный комплект: [инструкции](AGENTS.md), [документация](docs/index.md), [настройки](ai-dev-playbook/project.json).

Проверка структуры: `python3 ai-dev-playbook/scripts/playbook.py check --ready`.

Быстрый маршрут и итерации: [руководство](docs/user-guide/modes.md#быстрые-визуальные-итерации-в-workflow-v2). Quick доступен только при явно включённом workflow v2, сохраняет обычную карточку и требует явной приёмки инженера.

Локальный артефакт 0.2.0: [установка, обновление и явное подключение v2](ai-dev-playbook/rules/update.md#локальный-артефакт-020-и-workflow-v2-pb-036). Поддерживаются переходы из 0.0.2, 0.0.3 и 0.1.0; исходный проект пока использует legacy.
